Catat saat stok diterima dari gudang atau supplier. Pilih nama consumable, divisi penerima/pencatat, jumlah, tanggal, dan PIC. Stok akan bertambah otomatis.

Catat setiap pemakaian atau distribusi. Pilih nama consumable, divisi yang membutuhkan, jumlah, tanggal, dan PIC. Stok berkurang setelah transaksi berhasil.

ASSET EHA

Master data aset, status return dan repair, serta lokasi aktual aset

TERSIMPAN LOKAL
1 DAFTARKAN UNIT ASET

Input satu unit untuk setiap perangkat. Pilih jenis aset dan masukkan Serial Number unik sebagai identitas. Isi lokasi aktual, letak aset, serta status return dan repair.

2 PERBARUI PERPINDAHAN / STATUS

Gunakan tombol Edit saat aset berpindah divisi atau PIC, dikembalikan, maupun masuk proses perbaikan. Lengkapi nomor tiket Return atau Repair jika tersedia.

Standar pencatatan: satu baris = satu unit aset. Isi kolom “Letak Asset Saat Ini (Aktual)” dengan format yang mudah ditelusuri, misalnya “Divisi Sortir / PIC Rahman”, dan “Letak Asset” dengan lokasi fisik, misalnya “Area Sortir – Meja 2”. Serial Number tidak boleh duplikat.
